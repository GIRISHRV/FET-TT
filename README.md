# FET-TT (Quick Bell)

Personal timetable app for college. 

Scrapes the official grid and displays it in a clean mobile UI. Has a true-black OLED dark mode, frosted glass navigation, and some background stardust animations because why not.

## Setup for personal dev
1. `npm install`
2. `npm run dev`

The `public/data.json` is generated by a python script that fetches from the master schedule.
